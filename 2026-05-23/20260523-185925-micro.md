一个叫 CodeGraph 的工具刚在 GitHub Trending 上冒出来，它给 Claude Code、Cursor、Codex 这些 AI 编程助手预建了一张代码知识图谱。

实测数据挺硬：在 VS Code、Django、Tokio 等 7 个真实开源项目上跑基准测试，成本平均降了 35%，token 消耗少 59%，工具调用次数直接砍掉 70%。拿 VS Code 那 1 万个文件的仓库来说，回答同一个架构问题，没用 CodeGraph 时花了 $0.64、调了 23 次工具；用了之后 $0.42、7 次工具调用就搞定，零文件读取。

![colbymchenry/codegraph — Pre-indexed code knowledge graph for Claude Code, Codex](20260523-185925-micro-content-1.png)

原理不复杂——它把你项目的符号关系、调用链、代码结构提前索引好存进 SQLite，AI 不用再满世界 grep 和 read 文件，直接查图就行。100% 本地跑，数据不出机器。支持 19 种语言，还能识别 14 个框架的路由文件。安装就一行 curl 命令，macOS、Linux、Windows 都行。
