OpenPipe 放出了一个叫 ART 的强化学习训练框架，专门用来训练多步智能体。它用的是 GRPO 算法，支持 Qwen3.6、GPT-OSS、Llama 这些模型，直接在真实任务上做“在职培训”。

最狠的是他们跟 W&B 搞了个 Serverless RL 服务，2025 年初刚上线。训练成本直接砍掉 40%，速度还快了 28%。怎么做到的？共享推理集群跑 2000+ 并发请求，GPU 资源复用。以前配环境要折腾几小时，现在一个 API 调用就搞定，checkpoint 即时部署到 W&B Inference。

![OpenPipe/ART — Agent Reinforcement Trainer: train multi-step agents for real-wor](20260523-184826-micro-content-1.png)

框架本身开源，pip install openpipe-art 就能装。笔记本案例里有个狠活：Qwen 2.5 14B 训练出来的 ART·E 邮件搜索智能体，直接干翻了 OpenAI 的 o3。还有玩 2048、井字棋、MCP 服务器工具调用的例子，3B 小模型也能训。
