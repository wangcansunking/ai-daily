Databricks 的 Field Engineering 团队在 GitHub 上开源了一套 AI Dev Kit，专门给 Claude Code、Cursor、Windsurf 这类编程助手用的。仓库里塞进了 75 个以上可执行的 Databricks 工具，覆盖 Spark 声明式管道、Unity Catalog 治理、MLflow 实验追踪、模型服务部署这些场景。

安装走一句 shell 命令就能搞定，支持 Mac/Linux 和 Windows。除了命令行，还带一个叫 Visual Builder App 的全栈 Web 界面，部署 Lakebase 加 Databricks App 一条 deploy.sh 就完事。有意思的是，开启 --enable-mcp 参数后，这个应用直接变身 MCP 服务器，把 75+ 工具暴露给 Genie Code 和 AI Playground 用。

![Databricks Certified Gold Project](20260523-185206-micro-content-1.jpg)

安全方面团队动作很快，最近 litellm 1.82.7 到 1.82.8 版本曝出供应链问题，他们马上审计了依赖树，把 litellm 从主包移除，只在测试目录保留并固定到安全版本。
