# 无需月费！Presenton 开源 PPT 工厂：可接 OpenAI/Claude，支持导出 PPTX 和 PDF

> ai-daily · 2026 年 5 月 23 日 19:28 · 来源：GitHub Trending any

![](head.png)

刚刚冒出来的一个开源项目，直接把 Gamma、Beautiful AI 这类付费 PPT 生成工具的桌子掀了。

Presenton，Apache 2.0 协议全开源，支持 Docker 一行命令部署，也提供 Windows/Mac/Linux 桌面客户端。它最狠的一招是**完全不锁模型**——你可以接 OpenAI、Gemini、Claude，也可以接 Ollama 跑本地模型，数据全程留在自己机器上。生成的演示文稿能导出为标准 PPTX 和 PDF，还自带一套 AI 模板引擎，能从你现有的 PowerPoint 文件里直接扒版式生成新模板。

![presenton/presenton — Open-Source AI Presentation Generator and API (Gamma, Beau](content-1.png)

（让我愣神的是它甚至内置了 MCP 服务器，意味着你可以用 Claude Desktop 这类客户端直接调用它生成幻灯片。）

![Presenton Features](content-2.png)

没有月费、没有功能锁、没有数据送进别人家服务器。如果你手里有 API key，这就是一台永不停机的 PPT 工厂。
