Databricks 的 Field Engineering 团队在 GitHub 上开源了一套 AI Dev Kit，专门给 Claude Code、Cursor、Windsurf 这类 AI 编程助手用的。里面塞了 75 多个可直接执行的工具，覆盖 Spark 声明式管道、Databricks Jobs、Unity Catalog、模型部署这些场景。

有意思的是，他们为了这个项目专门搞了一次供应链安全审计。起因是 litellm 在 1.82.7 到 1.82.8 版本曝出安全事件，团队立刻排查了自己的依赖树，把 litellm 从主代码里全拔了，只留在测试目录里评估技能用，还锁死了安全版本。

![Databricks Certified Gold Project](20260523-185227-micro-content-1.jpg)

安装方式挺灵活，一条 curl 命令就能装到现有项目里，也支持指定工具集、切换全局/项目级安装。另外还有一个 Visual Builder App，能一键部署成带聊天界面的 Web 应用，打开 --enable-mcp 参数还能当 MCP 服务器用，直接给 Genie Code 喂工具。
