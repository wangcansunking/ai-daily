有个叫 CodeGraph 的工具，2025 年 7 月刚在 GitHub 上火了。它给 Claude Code、Cursor 这些 AI 编程助手做了个预索引的知识图谱，直接跑在本地，不联网、不上传数据。

实测数据挺硬：在 VS Code、Django、Tokio 等 7 个开源项目上跑了一遍，平均省了 35% 的费用、少用了 59% 的 token、工具调用次数砍掉 70%。Tokio 这个 Rust 项目表现最夸张，省了 52% 的钱，token 消耗降低 81%。

![colbymchenry/codegraph — Pre-indexed code knowledge graph for Claude Code, Codex](20260523-185952-micro-content-1.png)

原理不复杂——平时 AI 助手读代码得反复用 grep、glob 去扫文件，每次工具调用都在烧 token。CodeGraph 提前把代码里的符号关系、调用链、路由映射都建好了，存在本地的 SQLite 里。助手直接查图谱就行，不用满世界翻文件。VS Code 那个测试里，用了 CodeGraph 后只调了 7 次工具就答完问题了，没用的那个调了 23 次。
