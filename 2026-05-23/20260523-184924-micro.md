Andrej Karpathy 3 月发帖吐槽 LLM 编程四大坑：擅自假设、过度工程、乱改无关代码、不问清楚就动手。现在有人把这套观察做成了一个 CLAUDE.md 文件，放 GitHub 上两天就冲到 Trending。



![Karpathy 吐槽 LLM 编程的四大问题 → CLAUDE.md 四条原则的映射关系](20260523-184924-micro-schematic-1.png)



![multica-ai/andrej-karpathy-skills — A single CLAUDE.md file to improve Claude Co](20260523-184924-micro-content-1.png)

文件核心就四条规则：动手前先想清楚，别藏着疑问；代码能 50 行就别写 200 行；改代码时别顺手“优化”旁边的文件；把模糊需求转成可验证的测试，让模型自己循环跑通。

项目叫 multica-ai/andrej-karpathy-skills，MIT 协议开源。可以直接在 Claude Code 里装插件，也能用 curl 命令下到本地项目。作者还专门给 Cursor 配了 .cursor/rules 规则文件。Karpathy 原话是这么说的：别告诉模型该干什么，给它成功标准让它自己跑。
