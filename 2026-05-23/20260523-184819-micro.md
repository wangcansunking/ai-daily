OpenPipe 放出了一个叫 ART 的强化学习框架，专门给多步智能体做“在职培训”。它用 GRPO 算法训练 Qwen3.6、GPT-OSS、Llama 这些模型，让它们从实际任务里学经验，而不是靠标注数据硬灌。

最狠的一招是接入了 W&B 的无服务器 RL 训练服务，成本直接砍掉 40%，训练速度快了 28%。以前搭 GPU 环境要折腾几小时，现在几行代码就能跑起来，还能自动扩到 2000 多个并发请求。模型每存一个检查点，立刻就能用 W&B 推理服务上线。

![OpenPipe/ART — Agent Reinforcement Trainer: train multi-step agents for real-wor](20260523-184819-micro-content-1.png)

他们在邮件检索任务上拿 Qwen 2.5 14B 干翻了 OpenAI 的 o3，还搞出了 MCP•RL 这种能自动学会调用任何 MCP 服务器工具的花活。整个框架拆成客户端和服务端，你只管写奖励函数，训练和推理的脏活累活全丢给后端。
