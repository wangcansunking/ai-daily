如果你在 2025 年 4 月打开 GitHub Trending，会发现一个叫 Presenton 的项目冲上来了。它做的事情很直接：用 AI 生成 PPT，而且代码全开源，Apache 2.0 协议。跟 Gamma、Beautiful AI、Decktopus 这些商业产品不一样，Presenton 不锁订阅、不藏模型、不强制你把数据丢到别人的云上。

看它的部署方式就知道这东西冲着谁来的。你可以直接用 Docker 一行命令拉起来，也能下载 Electron 桌面应用跑在 macOS、Windows、Linux 上。桌面版不依赖浏览器，所有处理都在本地完成——你用自己的 API key 接 OpenAI、Gemini、Anthropic Claude，或者干脆用 Ollama 跑本地模型，全程数据不出机器。2025 年 4 月 16 日发布的版本里，它还加了个 ChatGPT 账号登录功能，用免费或付费的 ChatGPT 账号就能直接开始做 PPT，不用另外搞 API key。

![presenton/presenton — Open-Source AI Presentation Generator and API (Gamma, Beau](20260523-185636-article-content-1.png)

模板系统是另一个有意思的点。Presenton 允许你用 HTML 和 Tailwind CSS 自定义主题，还能从现有的 PowerPoint 文件里提取模板转成 AI 可用的设计。生成 PPT 的输入可以是文字提示，也可以直接上传文档。导出格式支持 PPTX 和 PDF，而且 PPTX 文件保留完整的编辑能力，不是那种一碰就乱的扁平导出。它还内置了 MCP 服务器，能用 Model Context Protocol 接口被其他工具调用生成演示文稿——这对把 PPT 生成嵌入自动化工作流的人来说是个实用功能。

![Presenton Features](20260523-185636-article-content-2.png)

多模型支持这块做得挺野。文字生成可以选 OpenAI、Google Gemini、Vertex AI、Azure OpenAI、Anthropic、LM Studio、Ollama 或者自定义兼容端点；图片生成能从 DALL-E 3、Gemini Flash 切到 Pexels、Pixabay 这类免费图库。你甚至可以混搭——文字用一个提供商的模型，图片用另一个。API key 完全由用户自己管理，花多少算多少，没有抽成也没有隐藏费用。如果不想让终端用户改 key，部署时设个环境变量 `CAN_CHANGE_KEYS=false` 就能锁死配置。

说实话，AI PPT 生成这个赛道已经挤了两年了，但大部分产品都在走 SaaS 订阅路线，月费从 10 美元到 30 美元不等。Presenton 直接开源丢出来的做法，对不想被绑在某个平台上的团队来说是个实在的选择。它不是什么颠覆性的技术突破，但胜在透明——代码能看、模型能换、数据能留本地。如果你已经在用 OpenAI 或 Anthropic 的 API，这东西等于白捡一个 PPT 生成前端。
